## How to run it

1. Write the 10 ideas as eval cases outside git (format: `evals/src/case.ts`; see `evals/sets/synthetic` for the shape) or generate the ideas in the app, accept them and generate the drafts on `/content/review/[ideaId]`. Both paths use the same pipeline.
2. Machine checks and the blind sheet:
   ```bash
   pnpm eval --provider live --set /path/to/g1-cases --judge --blind --g1
   ```
   It prints the cost estimate and asks first. The results JSON, the blind sheet (`*-blind.md`, `*-blind.csv`) and the key (`*-blind-key.json`, **not for the reviewers**) land in `evals/results/`.
3. Give each native reviewer the Markdown and the CSV; they fill `reads_as_native_1_5`, `not_a_translation_of_the_other_yes_no`, `approvable_yes_no`, `field_edits_needed`.
4. Ihor and Sergey open each idea on the review screen and rate "approvable with ≤ 3 field edits".
5. Fill the table below, decide, write the actions.
