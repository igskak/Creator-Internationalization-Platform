**Status: NOT RUN.** Everything the gate needs from the software is built (M5-00 … M5-10, M5-12 pending its legal decision). ## Order of work

1. Set up the Meta apps, accounts, testers and URLs: `docs/runbooks/meta-app-setup.md` (B-11).
2. Development environment: connect the test accounts, set `INSTAGRAM_ACCOUNT_ALLOWLIST` to their ids, run the dry-run and live smoke tests and the idempotency drill: `docs/runbooks/instagram-smoke.md`. Close V-08 and V-14 in the decision log with the results.
3. Production environment: `INSTAGRAM_PUBLISH_MODE=dry_run_only`, the production accounts connected and allowlisted, `publishing.enabled` off. Run one **dry run** per market from the review screen (an approved real carousel).
4. Test the kill switch (switch off and on in Settings → Instagram, with a reason) and run the token refresh once by hand (Trigger.dev dashboard → `refresh-instagram-tokens` → Test).
5. Close the legal items (B-13) and the ManyChat flows (B-12), or choose non-commercial first posts.
6. Switch the production environment to `live`, switch publishing on, publish the first three posts of one market (Sergey approves each before it is scheduled), then the other market.
7. Run `pnpm rc g2-check`, fill in the record below, decide.
